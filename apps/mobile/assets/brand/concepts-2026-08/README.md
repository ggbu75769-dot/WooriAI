# 우리아이 신규 로고 10종

기존 `우` 모노그램을 변형하지 않고 새로 만든 벡터 탐색안이다. 아직 제품 자산에는 적용하지 않았다.

| 번호 | 이름 | 핵심 인상 |
| --- | --- | --- |
| 01 | Orbit Family | 보호, 연결, 중심 |
| 02 | Woven W | 협력, 움직임, 현대적 |
| 03 | Moment Frames | 기록, 사진, 일상 |
| 04 | Tomorrow Page | 기록, 계획, 내일 |
| 05 | Family Knot | 유대, 가족, 포용 |
| 06 | Growth Rings | 성장, 시간, 안정 |
| 07 | Together Arcs | 보호, 균형, 따뜻함 |
| 08 | Record Path | 진행, 행동, 생산성 |
| 09 | Cradle Spark | 돌봄, 아이, 프리미엄 |
| 10 | Shared Table | 공동 관리, 생활, 신뢰 |

모든 원본은 512×512 SVG이며 배경과 심볼을 분리해 앱 아이콘, 단색 아이콘, 시작 화면으로 전개할 수 있다.
