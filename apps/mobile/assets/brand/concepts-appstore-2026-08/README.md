# 우리아이 앱스토어 레퍼런스 로고 10종

이전 10번 `Shared Table`을 1순위 기준으로 삼되 형태는 반복하지 않았다. 가족 공동관리라는 정체성을 `포용 / 인계 / 일정 / 보호 / 알림 / 기록 / 공유 공간 / 흐름 / 균형 / 생활 중심`의 서로 다른 단일 실루엣으로 재해석했다. 아직 제품 자산에는 적용하지 않았다.

| 번호 | 이름 | 핵심 인상 |
| --- | --- | --- |
| 01 | Embrace Core | 두 보호자, 아이 중심, 강한 인지성 |
| 02 | Family Handoff | 끊김 없는 공동 돌봄 |
| 03 | Family Day | 가족 일정과 생활 관리 |
| 04 | Care Bridge | 아이를 함께 받치는 보호자 |
| 05 | Care Signal | 기록과 알림의 공유 |
| 06 | Shared Notes | 생활 기록이 쌓이는 앱 |
| 07 | Round Table | 가족이 보는 하나의 중심 |
| 08 | Daily Thread | 세 사람의 이어진 하루 |
| 09 | Care Pair | 서로 다른 보호자의 균형 |
| 10 | Living Center | 가족 생활의 공동 허브 |

## 조사 기준

- Apple Design Awards 2026: 한 개의 지배적 실루엣, 제한된 팔레트, 작은 크기에서도 남는 중심 형태.
- FamilyWall: 가족 일정·목록·재정·메시지를 하나로 모으는 공동관리 포지셔닝.
- Baby Daybook / Sprout Baby Tracker: 가족 공유, 빠른 기록, 일상 패턴이라는 핵심 작업.
- Structured: 단색 배경 위 하나의 선명한 작업 심볼을 쓰는 생산성 앱 문법.

모든 원본은 512×512 SVG다. 앱 아이콘 마스크 안에서 여백을 확보했고, 글자·캐릭터·사진 없이 실루엣만으로 구분되게 만들었다.
