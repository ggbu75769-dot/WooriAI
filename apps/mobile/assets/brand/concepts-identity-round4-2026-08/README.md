# 우리아이 로고 탐색 Round 4

앞 세트의 기능 아이콘 같은 인상을 버리고, 하나의 고유 브랜드 마크 안에 `아이 비용 기록 + 다음 준비 + 가족 보호`를 결합했다. 실제 앱에는 아직 적용하지 않았다.

| 번호 | 이름 | 결합한 정체성 |
| --- | --- | --- |
| 21 | Nest Ledger | 아이 둥지 + 비용 기록 |
| 22 | Baby Wallet | 아이 + 가족 지갑 |
| 23 | Ready Nest | 준비 완료 + 안전한 둥지 |
| 24 | Care Meter | 아이 비용 + 준비 상태 |
| 25 | Woori Basket | 두 보호자 + 준비 바구니 |
| 26 | Growing Coins | 성장 단계 + 누적 비용 |
| 27 | Next Pocket | 기록 + 다음 준비 |
| 28 | Family Token | 가족 보호 + 아이 비용 토큰 |
| 29 | Care Balance | 예산 + 필요한 준비의 균형 |
| 30 | Woori Ribbon | W 리듬 + 아이 성장선 |

공식 팔레트 `#17324D / #FF6B4A / #FFD76A / #FFF9F3`만 사용했고 모든 원본은 512×512 SVG다.
