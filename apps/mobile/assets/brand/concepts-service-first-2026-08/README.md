# 우리아이 서비스 정체성 로고 확장 10종

기존 `Embrace Core`를 전체 1위로 고정하고, 서비스의 핵심을 더 직접적으로 보여주는 도전자 10종을 추가했다. 아직 실제 제품 자산에는 적용하지 않았다.

> 우리 아이에게 쓴 돈을 기록하고, 다음에 필요한 준비를 알려주는 가족 앱.

| 전체 순위/번호 | 이름 | 즉시 읽히는 서비스 의미 |
| --- | --- | --- |
| 1위 | Embrace Core | 두 보호자와 아이, 우리아이 브랜드의 감정 중심 |
| 11 | Child Ledger | 아이 비용 기록 |
| 12 | Ready Basket | 출산·육아 준비템 체크 |
| 13 | Record to Ready | 기록에서 다음 준비 추천으로 연결 |
| 14 | Family Wallet | 가족 공동 비용 관리 |
| 15 | Cost Timeline | 성장에 따른 누적 비용과 다음 단계 |
| 16 | Smart Checklist | 지금/곧 필요한 준비템 추천 |
| 17 | Care Budget | 아이 비용 예산과 리포트 |
| 18 | Buy–Record Loop | 구매 후 지출 기록으로 연결 |
| 19 | Growth Stack | 성장 단계별 비용과 준비 |
| 20 | Shared Total | 가족 기록이 하나의 총액으로 집계 |

설계 원칙은 64px 인지성, 한 아이콘당 최대 두 개의 의미층, 글자·사진·캐릭터 배제, 네이비·민트·코랄·옐로의 고정 브랜드 팔레트다.
