## 2. 하이파이 UI 이미지 생성 프롬프트

### GLOBAL 공통 하이파이 스타일

Create a high-fidelity iOS mobile app UI for a Korean parenting expense tracker app called “우리아이”. Visual direction: “as easy as Toss, as warm as a baby diary”. Use warm coral #FF8A7A as primary, mint #7DDCC7 as secondary, cream background #FFF8F1, white rounded cards, charcoal text #242424, soft shadows, rounded line icons, large readable Korean typography, 4-tab bottom navigation 홈/기록/준비템/리포트. No real brand logos, no product photos, no medical claims, no clutter. Use Korean copy exactly where provided.

### HOME-001 홈 하이파이

High-fidelity mobile UI for 우리아이 home dashboard. Top: “뽀미 · 임신 28주차”. Hero card: “지금까지 우리 아이에게 3,482,000원 들어갔어요”. Budget card with progress bar “426,000원 / 예산 600,000원”. Primary coral button “+ 지출 기록하기”. Section “지금 준비하면 좋아요” with three warm cards: 카시트, 아기욕조, 체온계. Recent records. Bottom tab active 홈. Soft emotional but clean finance-app style.

### EXP-001 빠른 기록 하이파이

High-fidelity mobile UI for quick expense entry. Title “뭘 기록할까요?” with helper text. Rounded chips for 기저귀, 분유, 젖병, 옷, 병원비, 검사비, 유모차, 카시트, 직접 입력. Amount input card showing 49,800원, date card 오늘, optional memo. Fixed coral bottom button “기록하기”. Use minimal, friendly Korean UX writing.

### ITEM-001 준비템 목록 하이파이

High-fidelity mobile UI for preparation item checklist. Tabs 지금 필요/곧 필요/이미 준비/필요 없음. Cards with colored necessity badges 필수/편의/선택, item name, short reason, estimated price range, small action buttons 비교하기 and 이미 샀어요. Include one affiliate-safe neutral card, no sponsored emphasis.
