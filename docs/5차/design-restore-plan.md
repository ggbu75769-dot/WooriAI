## 3. 원칙

1. **c20deeb 트리가 시각 스펙의 단일 소스**다. 화면 재작성 시 캡처가 아니라 `git show c20deeb:<파일>`을 읽고 구조·토큰을 옮긴다.
2. 라운드 13~52의 기능·정직성 계약(DNC 전부, 오프라인 아웃박스, 권한 게이트, 허위 표시 금지)은 한 줄도 후퇴하지 않는다. 기능을 c20deeb 문법 **안으로** 재배치한다.
3. 화면당 카드/구획 수에 상한을 두고(홈 기준 1히어로+3구획), 초과분은 우선순위 판정으로 접거나 하위 화면으로 이동한다.
4. 비세션 캡처(픽셀 락)는 이 복원의 **목표 상태**와 같은 계보이므로, 복원이 곧 재캡처 부채(6화면)를 해소하는 방향이다.

- 부족분을 공용 컴포넌트로 추출하고 화면들이 재사용하게 한다(픽셀 락 비세션 분기는 기존 렌더 유지).

### P2 — 화면 정합 (4트랙, 파일 무충돌)
- **T-홈**: 카드 다이어트 — 히어로(비용+예산 통합) / 자주 기록해요 칩 / 준비 현황 1장(prep-nudge·첫실행 가이드 통합) / 최근 기록. 주간 요약·마일스톤·누적·전월 비교는 우선순위 판정으로 최대 1장 노출 + 나머지는 리포트 탭으로 위임.
- **T-준비템**: "내 준비 목록" 구조 복원(진행률 히어로·분류별/시기별 세그먼트·검색·분류 섹션 카드·타일 그리드·보유/알아보기 pill). 현재 기능(찜·필수도·출산 전·오프라인 상태 변경·아이 전환) 통합. 상세(ITEM-002)는 캡처 문법(히어로 이미지 카드·예상 가격대·가격 비교/제품 정보 탭·행당 구매하기)에 현재 정직 규칙(실가격+확인 시각, 고지 인접) 유지.
- **T-지출·기록**: 바로 기록 타일 파스텔 원형 아이콘, 하단 고정 요약바("38,500원"), 분류별 빠른 품목 아코디언 시각. 기록 탭은 문법만 정돈.
