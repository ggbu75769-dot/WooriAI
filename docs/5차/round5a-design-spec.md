# Round 5A 디자인 고도화 스펙 (Mobbin·벤치마크 리서치 기반)

근거: Mobbin(Copilot Money·Buddy·Expensify 플로우, Dashboard/Logging/Empty State 패턴), Toss TDS·Toss Product Sans 원칙, 뱅크샐러드 BPL, YNAB 프로그레스, Huckleberry/BabyTime/베이비빌리(육아), 컬리/오늘의집(커머스), 공정위 제휴 고지 지침. 상세 출처는 리서치 보고(세션 기록) 참조.

**원칙: 코랄/크림 브랜드 유지, 구조 변경 최소화, 위계·일관성·상태 표현을 실서비스 수준으로.**

## D0. 디자인 토큰 (theme 확장 — 모든 화면의 기반)

### 컬러
```ts
coral:  { 50:"#FFF3F0", 100:"#FFE4DD", 200:"#FFC9BB", 300:"#FFA88E",
          400:"#F97B5C", 500:"#EF6644", 600:"#DB4F2E", 700:"#B93E23" }
// coral-500: 칩·활성 탭·아이콘 틴트 / coral-600: 채움 버튼·링크 (흰 글자 4.5:1 이상 — 구현 시 실측 재검증)
cream:  { bg:"#FBF4EC"(현 배경 유지), surface:"#FFFFFF", surfaceAlt:"#FFF9F3" }
text:   { primary:"#3D3733", secondary:"#6E645C", tertiary:"#9C918A" }
semantic:{ success:"#2E9E6B", warning:"#E8A13A", danger:"#D3382F", info:"#5B7FA6" }
```
- **지출 금액 기본색 = text.primary** (전부 빨간 가계부 금지). 수입/환불만 `+` 접두 + success.
- 예산 프로그레스: 정상 coral-500 → 80% 이상 warning → 100% 초과 danger (YNAB).
- 카테고리 8~10색 고정 팔레트(웜 파스텔 계열)를 정의하고 도넛·행 아이콘·상세에 동일 적용 (Copilot).

### 타이포 (금액 규칙)
- 모든 금액에 `fontVariant: ["tabular-nums"]`.
- 표기: `12,000원` 형식(₩ 대신), '원'은 숫자 대비 1단계 작게·가늘게. 포맷은 `Intl.NumberFormat('ko-KR')` 헬퍼 일원화.
- 위계: 히어로 금액 30px/800 · 섹션 합계 17px/700 · 행 금액 15px/600. 숫자는 한글보다 한 단계 굵게 (Toss).

### 공통 컴포넌트 (TDS ListRow 사고방식)
- `ListRow`: 좌 카테고리 컬러 원형 아이콘 / 중앙 타이틀+서브 / 우 금액·값. 기록·설정·상세 전부 이걸로 통일.
- `Skeleton`: 로딩은 전부 스켈레톤(스피너·"잠시만요" 텍스트 카드 제거). 카드/행 실루엣 + 은은한 펄스.
- `EmptyState`: 4종(최초/검색없음/완료/교육) — 최초·완료는 따뜻한 일러스트 자리 + CTA.
- `StageBadge`: 아이 단계 칩(코랄 배경 50 + 글자 700) — 홈 헤더와 준비템 필터가 동일 스타일 공유.

## D1. 탭바
- 비활성 outlined / 활성 filled + coral-500 틴트, 라벨 4개 상시 표시.
- 아이콘 패밀리 통일(획 두께·비례 일치). 현 커스텀 글리프를 하나의 세트로 재작성.

## D2. 홈 탭
1. 상단 아이 헤더: 이름 + `StageBadge`("생후 7개월") — 준비템과 연동 암시.
2. **히어로 카드**: "이번 달" 라벨 + `1,234,000원`(30px) + 예산 프로그레스 바 1개 + 아래 작은 행(오늘 지출 · 전월 대비 ±%). 그 외 수치 카드 정리.
3. **빠른 기록**: 히어로 아래 자주 쓰는 카테고리 칩 3~4개(원탭 → 금액 키패드, 기본값 오늘/해당 카테고리, 저장 1탭) + `+ 직접 입력`.
4. 인사이트 한 줄 카드 1장(아이콘+한 문장, 예: "기저귀 지출이 지난달보다 12% 줄었어요").

## D3. 기록 탭
1. 스티키 날짜 헤더: "7월 12일 (토)" + 우측 일 합계.
2. 행 = `ListRow`(카테고리 컬러 아이콘 / 항목명·메모 / 금액). 선물 등은 소형 뱃지.
3. 동기화 상태: 행별 아이콘 대신 **미동기화 존재 시에만 상단 얇은 상태 라인**("2건 동기화 대기 중" → 탭하면 sync-status). 충돌/실패도 이 라인에서 진입.
4. 삭제 = 즉시 + 스낵바 실행취소(기존 2단계 확인 흐름이 테스트로 고정돼 있으면 유지하되 시각만 정리 — 회귀 우선).
5. 카테고리 필터 칩 행 유지, 스타일만 토큰화.

## D4. 준비템 탭
> **적용 조정(2026-07-13)**: 현행 준비템 탭은 체크리스트가 아니라 ITEM-001로 고정된 **추천 상품 피드**(ProductCard, 준비했어요/괜찮아요)다. 체크 행 전환(§3)은 스타일이 아닌 제품 구조 변경이라 **보류(제품 결정 필요)** — 이번 라운드는 피드 구조를 유지한 채 아래만 적용한다.
1. 상단 진행 요약(축소형): 진행 바 + "N개 준비 완료 · M개 남았어요" (prepared 읽기 전용 쿼리 허용, 실패 시 요약만 숨김).
2. 단계 칩 = `StageBadge` 스타일 공유.
3. ~~체크 행 전환~~ → 보류. ProductCard 내부 색·타이포·간격만 새 토큰으로 정돈(구조 불변).
4. 상세/구매: 제휴 고지는 CTA 바로 위 캡션(즉시 보임 — 공정위) 유지·강화.

## D5. 리포트 탭
1. 도넛: 상위 5~6 카테고리 + 기타, **중앙 홀에 월 총액**, 조각 색 = 카테고리 팔레트.
2. 월 네비게이션 "‹ 2026년 7월 ›" 유지, 미래 월 비활성.
3. 비교 카드 2장: 전월 대비 ±%, 가장 증가한 카테고리.
4. 최근 6개월 바 차트(단색 코랄, 당월만 진하게).
5. 단계 축 인사이트 1장: "생후 7개월 차 이번 달 지출" (육아 차별점).

## D6. 로딩·빈 상태 전면 교체
- "…불러오고 있어요 / 잠시만요" 텍스트 카드 → 화면별 스켈레톤.
- 오류 카드: "불러오지 못했어요 + 다시 시도" 구조는 유지하되 토큰 스타일 적용.
- 빈 상태: 최초 사용(기록 유도 CTA), 준비템 전부 완료(축하+다음 단계 미리 보기).

## D7. 앱 아이콘 (1안 심볼형 채택)
- 코랄(coral-600→400 미세 그라데이션 허용) 배경 + 크림 심볼: **동전(원) + 하트** 결합 마크 — 육아의 온기 + 가계부 신뢰.
- 심볼 크기 40~50%, 텍스트·그림자 금지. `apps/mobile/assets`의 icon/adaptive-icon/splash 교체, app.json 배선 확인.
- 2안(한글 '우' 레터폼)은 후보로 문서만 유지.

## 구현 순서·회귀 규칙
1. **F(파운데이션)**: theme 토큰 + ListRow/Skeleton/EmptyState/StageBadge + 탭바 + 금액 포맷 헬퍼 — 단일 executor.
2. **S(화면)**: 홈/기록/준비템/리포트 각 화면 적용 — F 이후, 파일 겹침 없게 분배.
3. **I(아이콘)**: 에셋 생성·교체.
- 기존 플로우 테스트(소스 문자열 검증)는 **동작·데이터 로직 회귀 금지** 전제에서 문구/스타일 단언만 새 스펙으로 갱신 허용.
- 픽셀락: 이 리디자인은 기준 이미지 자체를 의도적으로 교체하는 작업 — `ui-pixel-lock-flow` 계약 테스트는 새 토큰 기준으로 갱신하고, QA-101 재측정 대상임을 notes에 기록.
- 사용자 노출 문구(오프라인 "기기에 저장했어요…" 등 계약 문구)는 변경 금지.
