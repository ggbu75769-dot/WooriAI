1. 개요 · 범위

본 문서는 우리아이 모바일 앱 리디자인의 화면 단위 명세를 정의해요. 핵심 변경은 하단 내비게이션 4탭 → 5탭 확장(가장 오른쪽에 프로필 추가)과, 각 화면에 흩어져 있던 아이·가족·예산·설정 진입점을 프로필 탭으로 통합하는 것이에요. 모든 화면은 우리아이 디자인 시스템 v1.0 시드 토큰과 P0 컴포넌트 인벤토리를 사용해요.

3. 공통 규칙

  • 터치 타깃 최소 48dp · 입력 52dp · 버튼 48/52dp · 앱바 56dp · 하단 내비 64dp. 4pt 그리드, 화면 패딩 20/24/32dp.
  • 금액은 항상 "1,234,000원" — 콤마 구분, 원 접미(₩ 금지), 테이블 숫자. 수입·환불만 + 접두와 success 색.
  • 상태 언어: 알아보기 → 예정 → 주문 → 보유 → 대여 → 선물 → 교체 → 종료. 색만으로 상태를 구분하지 않아요(라벨 병기).
  • 0건 상태는 설명 + CTA로 표시하고 가짜 차트·데이터를 쓰지 않아요. 기록 3건 미만이면 차트 대신 빈 상태.
  • 실패 시 입력을 보존하고 사과 + 행동 안내: "완료하지 못했어요. 입력은 보존되었으니 다시 시도해 주세요."
  • 모든 목록 화면 하단에 SyncStatusBar(동기화 상태) 노출. 모션 120/180/240ms, cubic-bezier(0.2,0,0,1).
