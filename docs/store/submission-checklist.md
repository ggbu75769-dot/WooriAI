## 0. 제출 전 선행 조건 (아침에 먼저 확인)

- [ ] **법적 문서 + 지원 사이트 호스팅**: `infra/legal/`(처리방침·약관·계정 삭제 안내)과
      `infra/site/`(랜딩·FAQ·지원 — SITE-113)의 [대괄호] placeholder(운영 주체명, 지원
      이메일, 호스팅 수탁자, 시행일) 전부 교체 후 **Cloudflare Pages 무료 플랜에 정적
      호스팅**. 산출물 합치기·배포 절차·Play Console URL 매핑은 `infra/site/README.md`.
      HTTPS URL 확보.
- [ ] **계정 삭제 웹 페이지**: `infra/legal/account-deletion.html`로 준비됨 — 위 호스팅에
      포함해 배포하면 Data Safety의 계정 삭제 URL(`…/account-deletion.html`) 입력 가능.
      (코드/문서상 블로커는 해소 — placeholder 교체+배포만 남음. `docs/store/data-safety-answers.md` §A 참조)
- [ ] 지원 이메일 계정 개설 및 수신 확인.
- [ ] 릴리즈 AAB(`pnpm android:build-aab` — REL-011 원커맨드, keystore env 4종 + 앱 env 4종
      필요, release keystore 서명 자동 주입)와 versionCode 확정. (env 없이 gradle 직접 실행 금지
      — debug 서명 AAB는 Play 업로드 거부, `docs/5차/launch-72h-plan.md` §3.2)
- [ ] 스크린샷·그래픽 자산 완료(`docs/store/play-listing.md` §5–6 체크리스트).

## 1. 앱 생성 및 스토어 등록 정보

- [ ] Play Console → 앱 만들기: 이름 `우리아이 - 아이 지출 기록·준비템 체크`,
      기본 언어 한국어, 앱(게임 아님), 무료.
- [ ] 스토어 등록정보: `docs/store/play-listing.md`의 짧은/전체 설명 붙여넣기.
- [ ] 그래픽 자산 업로드(512 아이콘, 1024×500 피처, 스크린샷 4~8장).
- [ ] 카테고리: 육아(Parenting). 태그 선택.
- [ ] 연락처 정보(지원 이메일 필수) 입력. 지원 URL(선택)은 배포한 `…/support.html`
      (`infra/site/README.md`의 URL 매핑 표 참고).

## 2. 앱 콘텐츠(App content) 섹션 — 문항별 답 가이드

### 2.1 개인정보처리방침
- [ ] 호스팅한 처리방침 URL 입력.

### 2.2 광고
- [ ] **"앱에 광고가 포함되어 있나요?" → 아니요.** (광고 SDK 없음. 단, 스폰서 상품
      노출을 시작하면 재신고 — data-safety-answers.md §D)

### 2.3 앱 액세스 권한 (App access)
- [ ] 로그인이 필요한 앱이므로 **심사용 접근 방법 제공** 필요. 카카오 계정 테스트
      계정(테스트용 카카오 ID/PW) 또는 심사용 안내를 등록. [테스트 계정 준비 — 후속 확인]

### 2.4 콘텐츠 등급 (IARC 설문)
- [ ] 카테고리: **유틸리티/생산성/커뮤니케이션 등 "기타 앱"** 계열 선택(게임 아님).
- [ ] 폭력·성적 콘텐츠·욕설·공포: **없음**
- [ ] 도박(실제 화폐·시뮬레이션): **없음**
- [ ] 마약·주류·담배 언급: **없음**
- [ ] 사용자 간 상호작용(채팅/콘텐츠 교환): **없음** — 커뮤니티 기능 없음(DNC-016).
      가족 초대는 폐쇄형 공유이며 IARC가 묻는 불특정 사용자 간 상호작용이 아님.
- [ ] 사용자 위치 공유: **없음**
- [ ] 개인정보 교환: 콘솔 문항 문구에 따라 답 — 앱 내에서 타 사용자와 개인정보를
      "교환"하는 기능은 없음.
- [ ] 디지털 구매: **없음**(인앱결제 없음. 외부 쇼핑몰로의 아웃링크는 인앱 구매 아님)
- 예상 결과: 전체이용가(3+) 수준. **단, 앱의 "대상"은 아동이 아님** — 아래 2.5에서 명확히.

### 2.5 타겟층 및 콘텐츠 (Target audience)
- [ ] 대상 연령: **만 18세 이상**만 선택. (자녀 *정보*를 다루지만 자녀 *대상* 앱이
      아님 — 보호자 대상 가계부/육아 도구. 13세 미만 대상 아님으로 답해 가족 정책
      대상에서 제외)
- [ ] "아동의 관심을 끌 수 있는 앱인가?" → **아니요** (지출 기록·예산 도구, 아동 유인
      요소 없음).

### 2.6 데이터 안전 (Data safety)
- [ ] `docs/store/data-safety-answers.md`의 표를 **문항 순서대로 그대로** 입력.
      수집: 예 / 공유: 아니요 / 전송 중 암호화: 예 / 삭제 요청: 예.
- [ ] 계정 삭제 URL 입력(§0에서 배포한 `…/account-deletion.html`).

### 2.7 기타 신고 항목
- [ ] 뉴스 앱: 아니요 / 코로나19 앱: 아니요 / 정부 앱: 아니요
- [ ] 금융 기능(Financial features) 신고: **해당 없음** — 대출·결제·투자 기능 없음.
      개인 지출 "기록" 도구는 규제 대상 금융 서비스가 아님. 콘솔이 요구하면
      "해당 기능 없음"으로 선언.

## 3. 릴리즈 준비 및 제출

- [ ] **내부 테스트 트랙**에 AAB 업로드 → 테스터(본인 계정) 등록 → 설치 링크로
      실기기 자가 설치 검증(카카오 로그인, 지출 기록, 오프라인→동기화, 삭제 플로우,
      제휴 고지 노출 확인).
- [ ] 문제 없으면:
  - 조직(사업자) 계정: **프로덕션 트랙 생성 → 국가(대한민국) 선택 → 심사 제출.**
  - 개인 계정(2023-11 이후 생성): **비공개 테스트 시작 + 테스터 20명 모집 개시**
    (14일 요건 — launch-72h-plan.md §0).
- [ ] 출시 노트(ko-KR) 작성: "우리아이 첫 출시예요. 지출 기록, 준비템 체크리스트,
      100일 리포트, 가족 공유를 담았어요."

## 4. 제출 직후

- [ ] Play Console 사전 출시 보고서(pre-launch report) 크래시 확인.
- [ ] 심사 상태 모니터링(보통 수일). 반려 시 사유별 대응 — Data Safety 불일치가 최다
      반려 사유이므로 `data-safety-answers.md` ↔ 처리방침 ↔ 실제 앱 동작 3자 일치 재확인.
- [ ] 크래시 모니터링: Play 자동 수집으로 시작(Sentry는 출시 후 1주 내 — 72h 플랜 §4).

## 요약: 답이 정해진 3대 문항

| 문항 | 답 | 한 줄 근거 |
|---|---|---|
| 자녀 대상 앱인가 | **아니요 — 보호자(성인) 대상** | 아동이 사용하는 앱이 아니라 보호자가 아동 정보를 입력하는 도구 |
| 광고 포함 | **아니요** | 광고 SDK·배너 없음 (스폰서 상품 운영 시작 시 재신고) |
| 인앱결제 | **없음** | 결제 기능 없음. 외부 쇼핑몰 아웃링크(제휴 고지 포함)만 존재 |
