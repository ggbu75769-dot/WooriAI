### WALK-20260730-03 — CLOSED

- 재현: Android 준비 품목 상세에서 안전한 HTTPS 판매처 CTA를 누른다.
- 수정 전: Chrome 설치·초기화, manifest HTTPS query, shell ACTION_VIEW 성공 상태에서도 앱은 `판매처 페이지를 열지 못했어요`만 표시했다.
- 원인: `Linking.canOpenURL`을 다른 객체의 메서드로 복사해 호출하면서 React Native `Linking` 수신자가 사라졌고 내부 `this._validateURL()`에서 동기 TypeError가 났다.
- 수정: `Linking.canOpenURL(url)` 래퍼로 수신자를 보존하고 사전 조회는 참고값으로만 사용. native open 실패 시 기존 `expo-web-browser` Custom Tab으로 복구하며 `LOCKED`는 실패로 처리한다.
- 실패 폐쇄: unsafe URL은 열지 않고, 실제 opener 실패 시 transient follow-up을 제거하며 사람말 오류를 유지한다. 진단 로그에는 URL·아이 정보 없이 오류 종류만 남긴다.
- 재발 방지: `PurchaseOfferAction.test.tsx`와 `purchase-followup.test.ts`에서 수신자 보존, false-negative, Custom Tab 복구, LOCKED, open 실패 정리를 검증한다.
