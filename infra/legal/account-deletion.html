우리아이 계정 삭제 안내

우리아이 앱은 앱 안에서 직접 계정을 삭제할 수 있습니다. 별도의 문의나 대기 없이 즉시 처리됩니다.

1. 앱에서 계정 삭제하기

  1. 우리아이 앱 실행 → 하단 더보기 탭
  2. 설정 → 개인정보 관리
  3. 계정 삭제 선택 — 삭제될 데이터(아이 프로필, 지출 기록 등)를 먼저 보여드립니다
  4. 안내 문구를 입력해 확인하면 삭제가 완료됩니다

2. 삭제되는 데이터

  • 카카오 계정 연결 정보(식별자·표시 이름·이메일)
  • 아이 프로필(애칭·출생일/출산예정일), 지출 기록, 예산, 준비물 체크 상태
  • 가족 공유 구성원 정보, 등록된 기기(푸시 토큰), 로그인 세션 전체(즉시 무효화)

삭제 요청 즉시 모든 접근이 차단되며, 삭제 처리된 데이터는 30일 이내에 서버 저장매체에서 완전 파기됩니다(파기 주기는 환경 변수로 조정 가능, 기본 30일). 자세한 내용은 개인정보처리방침을 확인하세요.

3. 앱을 사용할 수 없는 경우

앱 접근이 불가능한 상태에서 삭제를 원하시면 가입 카카오 계정 정보를 적어 [지원 이메일 주소]로 요청해 주세요. 본인 확인 후 처리해 드립니다.

운영자: [운영 주체명] · 이 페이지는 Google Play 데이터 안전 요건의 계정 삭제 안내 URL로 사용됩니다.
