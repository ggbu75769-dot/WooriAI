이메일: [지원 이메일]

문의 시 아래 내용을 함께 적어주시면 더 빠르게 도와드릴 수 있어요.

  • 사용 중인 기기와 OS 버전 (예: Galaxy S24, Android 15)
  • 앱 버전 (앱 > 더보기 > 설정에서 확인)
  • 문제가 발생한 화면과 상황 (가능하면 스크린샷 — 개인정보는 가려주세요)

접수 후 순차적으로 답변드려요. 문의 전에 자주 묻는 질문도 확인해 보세요.

계정·데이터 삭제

우리아이는 앱 안에서 직접 계정과 데이터를 삭제할 수 있어요. 별도의 문의나 대기 없이 즉시 처리돼요.

앱에서 계정 삭제하기

  1. 우리아이 앱 실행 → 하단 더보기 탭
  2. 설정 → 개인정보 관리
  3. 계정 삭제 선택 — 삭제될 데이터(아이 프로필, 지출 기록 등)를 먼저 보여드려요
  4. 안내 문구를 입력해 확인하면 삭제가 완료돼요

삭제 요청 즉시 모든 접근이 차단되고, 삭제 처리된 데이터는 30일이 지나면 서버 저장매체에서 완전히 파기돼요. 아이 프로필만 삭제하거나 가족 공유(가구)에서만 탈퇴하는 것도 같은 화면에서 할 수 있어요.

앱에 접근할 수 없는 경우의 삭제 요청 방법을 포함한 자세한 절차는 계정 삭제 안내 페이지를 확인하세요.
